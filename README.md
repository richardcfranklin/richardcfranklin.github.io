# Richie Franklin portfolio

A static HTML/CSS site for GitHub Pages. No build step or server is required.

## Publish

Upload the five `.html` files, `style.css`, and the `assets` folder to the root of your `USERNAME.github.io` repository, replacing the temporary `index.html`. Keep the folder structure intact. GitHub Pages should be set to **Deploy from a branch → main → /(root)**.

## Edit

- Change copy directly in each HTML file.
- Replace `assets/portrait.jpg` if you want a newer portrait.
- Add web-sized photographs and book covers to `assets/`, then replace the labeled placeholders.
- Confirm the 2017 YouTube demo and acting credits still represent your work.
- Add purchase links and a contact method when you choose to make them public.

The source archive also had an obsolete PHP settings file and an unrelated template page. Neither belongs in a public static site.
